<h1>Calculadora de pré-build Genshin Impact</h1>

<h3>Introdução</h3>
<p>Eu, como um jogador de genshin impact, precisava fazer diversos cálculos para equilibrar minhas builds(Organização dos itens do personagem.)</p>
<hr/>

<h3>Funcionalidades</h3>
<p>Atualmente, ele só serve para calcular os valores da build que deseja. Porém futuramente pretendo adicionar uma funcionalidade que acompanha sua build, que o usuário consiga cadastrar os artefatos e o programa sugira alterações!   
<hr/>

<h3>Como funciona?</h3>
<p>Pra quem ja tem familiaridade com o jogo, é bem simples! você precisa ter em mente apenas algumas coisas:</p>
<ol>
  <li>Se o personagem quando upa, ganha taxa ou dano crítico.</li>
  <li>Reconhecer se a arma que vai utilizar ganha taxa ou dano crítico.</li>
  <li>O cv(Critical value) que deseja alcançar nos seus artefatos.</li>
  <li>Se o conjunto de artefatos utilizado influencia no crítico.</li>
</ol>
<p>Ao rodar o código basta apenas responder as perguntas e esperar os resultados!</p>
<hr/>
